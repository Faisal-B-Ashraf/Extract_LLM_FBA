SUMMARY STATISTICS:
================================================================================

Error Distribution:
- False Positive Extraction: 6 cases (50.0%)
- Wrong Value Extraction: 4 cases (33.3%)
- Missing Critical Context: 1 case (8.3%)
- Confusion with Non-Minimum Flow: 1 case (8.3%)

Primary Failure Mode: FALSE POSITIVES (50%)
- Model tendency to extract values even when documents explicitly state 
  "no minimum flow required" or don't mention minimum flows at all
- This suggests over-extraction bias in the complex pipeline

Secondary Failure Mode: WRONG VALUES (33.3%)
- Numeric errors ranging from 60% to 2800% deviation
- Includes both wrong values from document and wrong interpretation of seasonal schedules
- Suggests confusion between different flow types in document
  (e.g., maximum capacity vs minimum flow, inflow vs outflow)

Key Finding:
The 70B model's errors are primarily false positives (extracting when shouldn't) 
and wrong values (extracting incorrect numbers), NOT failure to extract when 
requirements exist.
